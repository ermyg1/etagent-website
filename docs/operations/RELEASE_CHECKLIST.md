# Release Checklist

Use this checklist for every production release of the E.T Agent Website.

## Repository

- [ ] `git status` clean
- [ ] Correct branch
- [ ] Latest changes pulled

## Build

- [ ] `npm install`
- [ ] `npm run lint`
- [ ] `npm run build`

## Deployment Package

- [ ] `index.html` exists
- [ ] `assets/` exists
- [ ] `.htaccess` exists

## Deployment

- [ ] `assets/` replaced
- [ ] `index.html` replaced
- [ ] `.htaccess` uploaded

## Hostinger

- [ ] Cache cleared

## Verification

- [ ] Homepage
- [ ] Governance model
- [ ] Governance demo
- [ ] Trust centre

## Desktop

- [ ] Verified

## Mobile

- [ ] Verified

## Release

- [ ] Deployment successful
